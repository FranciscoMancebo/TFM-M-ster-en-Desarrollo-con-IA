## Regla de evidencia

- **Hecho:** incluye fuente, fecha o dato anonimizado.
- **Interpretación:** explica qué puede significar.
- **Decisión:** vincula evidencia, requisito y cambio.
- **Hipótesis:** permanece pendiente y no se presenta como conclusión.

No se almacenan datos que identifiquen participantes. Las demostraciones utilizan usuarios y marcas ficticios.
