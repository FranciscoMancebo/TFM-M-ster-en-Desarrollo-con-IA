# Investigación inicial

Esta carpeta contiene los artefactos de descubrimiento de la fase 0. Separarlos de los requisitos permite distinguir lo observado de lo supuesto y registrar cuándo una hipótesis queda validada, refutada o pendiente.

## Documentos

| Documento | Propósito |
| --- | --- |
| [Análisis de referentes](01-analisis-de-referentes.md) | Comparar soluciones existentes con criterios comunes e identificar oportunidades. |
| [Guion de entrevistas](02-guion-de-entrevistas.md) | Realizar entrevistas consistentes sin dirigir las respuestas. |
| [Backlog inicial](03-backlog-inicial.md) | Convertir el alcance en entregas priorizadas y verificables. |

## Regla de evidencia

- **Hecho observado:** incluye fuente, fecha o evidencia de entrevista.
- **Interpretación:** explica qué podría significar el hecho.
- **Decisión:** indica qué cambia en el producto y por qué.
- **Hipótesis:** sigue pendiente de validación y no se presenta como conclusión.

Los datos de entrevistas no se subirán al repositorio si permiten identificar a una persona. Solo se conservarán notas anonimizadas y resultados agregados.
