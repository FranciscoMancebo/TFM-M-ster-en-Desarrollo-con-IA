# Registro de decisiones de arquitectura (ADR)

Un ADR documenta una decisión con impacto relevante. No es una defensa retrospectiva: se crea cuando la decisión se toma y puede quedar reemplazado por otro ADR.

## Estados

- Propuesto
- Aceptado
- Rechazado
- Reemplazado por ADR-XXXX
